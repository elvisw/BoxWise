静态示意，不是可操作应用。全部离线、无 JS、无网络，照片为自绘 SVG。示意图的触控尺寸不按 1:1；新增的「查看位置照片」入口按 44×44 CSS px 设计，既有树行与物品卡不重做。本页不证明真实应用、320px、200% 文本缩放或读屏已经通过。
