管理位置：描述和照片是同一张表单里的可选资料

新建与编辑共用现有「管理位置」对话框里的同一表单。标题栏和底部「保存 / 取消」固定，正文是唯一滚动区；已保存照片默认折叠成状态文字，展开后才加载。照片上传失败时位置和描述已保存，表单留在编辑状态，可重试或稍后补传。

静态示意，不是可操作应用。全部离线、无 JS、无网络，照片为自绘 SVG。示意图的触控尺寸不按 1:1，新增控件按 DESIGN.md 至少 44×44 CSS px；本页不证明真实应用、320px、200% 文本缩放或读屏已经通过。

1 · 新建位置：可选描述与照片

名称、上级位置、描述、照片依次排列；底部操作区固定，字段再多也能直接保存或取消。

实现后验收（本静态稿不能证明）

在真实应用中检查 320×640 CSS px、200% 文本缩放、横屏、键盘和读屏：无横向滚动；保存/取消/X/关闭/重试/「查看位置照片」/拍照/选图均可达且焦点不被裁剪区遮挡；管理表单正文滚动而操作区固定；提示条在失败、部分成功、结果未知时获得焦点并滚入视口；44×44 点击区域按实际 computed box 测量。长位置树另做人工可达性验收。

示意图中的位置、物品与姓名为 Story 中已有演示内容；照片框内为自绘 SVG 线稿，不代表真实照片。此页只用于确认布局关系，不是可操作应用，也不代表最终设计审核或真实应用验证已完成。
