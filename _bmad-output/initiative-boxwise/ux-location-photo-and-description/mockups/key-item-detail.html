两个照片对象的边界

物品照片回答「这是什么」。物品卡缩略图与详情大图保持现状；本功能不改其尺寸、裁切或占位。
位置照片回答「在哪个抽屉/柜子/箱子里」。只在「查看位置照片」点击后，于共用弹窗中按 contain 完整显示。不进入物品卡或详情主图。
入口位置物品详情元数据区，紧跟「位置: A → B → C」；空间足够时同行，长路径/窄屏时自然换行。编辑模式不显示。
加载时机入口可见性来自位置元数据；点击前不请求照片文件。图片加载失败不显示破图，弹窗内提供重试与关闭。无法确定照片有无时不显示入口，也不试探图片 URL。
