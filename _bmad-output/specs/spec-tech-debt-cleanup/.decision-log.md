## 2026-06-02: Open Questions 解决

**Q1: Bootstrap 本地文件放置位置？**
→ Server `wwwroot/lib/bootstrap/`。Identity 布局页由 Server 端渲染，`~/lib/...` 路径由 Server 的 `UseStaticFiles` 解析，Client `wwwroot/` 不可达。已更新 Constraint。

**Q2: Identity 汉化是否包括验证错误消息？**
→ 不包括。框架资源文件生成的错误消息需要 `RequestLocalization` + 卫星程序集，不属于"替换字符串"工作。CAP-5 success 条件已明确限制为 `.cshtml` 静态文本。已更新 CAP-5 描述。
